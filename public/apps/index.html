Device apps

Open this page on the device you're setting up, then download and install. Android asks you to allow "install unknown apps"; Windows warns about an unrecognised app — both are expected.

Kiosk Sunmi K2

Locks the device to the self-service menu: fullscreen, home and recents blocked, starts on boot. Staff settings and exit: tap any corner 3 times, or press volume-down 3 times.

Download Kiosk app
  1. Install, open it once.
  2. Tap any corner 3 times → Make this the home app → always.
  3. Tap any corner 3 times → Keep running in background.

Print Agent Android & Windows tills

Prints tickets and receipts on the till's printer — a Sunmi built-in printer or a USB printer, and on Windows a network printer too — even with the till app closed and the screen off. One app for every till: this button gives you the right version for the device you're on.

Download Print Agent

  1. Open the download, allow install unknown apps if Android asks, and tap Install.
  2. Open Print Agent, pick the store and enter the store manager PIN.
  3. Printer: USB printer if the printer is plugged in by cable, Sunmi built-in printer if it prints from the till itself. Avoid Automatic on a Sunmi till with a USB printer — it looks for a built-in printer and nothing prints.
  4. Tap Print a test slip.
  5. Allow it to run in the background.
  1. Double-click the download. Windows says “Windows protected your PC” — choose More info, then Run anyway. That is expected.
  2. Pick the store from the list.
  3. Pick the printer. USB printers and any printer found on the network are both listed — no addresses to type.
  4. Enter the store manager PIN. It is needed once and then deleted.
  5. Say yes when it offers to run in the background. It then starts with the machine, with no window to close.

Everything after that is in Admin → Printers: the name, what it prints, how many copies, and which printer it drives.

Nothing printing? Open a command prompt in that folder and run ChocoberryPrintAgent.exe -check. It tests every step and says which one fails.

Other version: Android · Windows

Customer Display Sunmi tills with a rear screen

Shows the store's posters on the screen facing the customer, instead of a copy of the till, and the order, amount and change while the till takes payment. Posters are set in Admin → store → Branding → Customer display.

Download Customer Display
  1. Install it on the till and open it.
  2. Pick the store, then the till this screen is on.
  3. Tap Allow display over other apps, switch it on for Customer Display, and come back.
  4. Tap Keep running in background. It starts by itself when the till is switched on.
Already installed? Installing again updates the app and keeps its settings.
